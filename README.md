# Habitarc 🌙

Habitarc is a beautifully designed, dark-themed self-improvement and habit tracking application. Built with React and Vite, it helps you track your daily habits, sleep patterns, weekly check-ins, and monthly reflections, all within a sleek, modern interface.

## Features ✨

- **Habit Tracker**: Monitor daily habits with visual progress and completion percentages.
- **Sleep Tracker**: Log your nightly sleep hours and view trends through intuitive area and pie charts.
- **Weekly Check-In**: Review your week, track accomplishments, and set goals for the next one.
- **Monthly Reflection**: A dedicated space to reflect on the past month and plan ahead.
- **Dashboard**: A high-level overview of your progress and insights.
- **Responsive Design**: A premium dark-mode aesthetic with neon accents, optimized perfectly for both desktop and mobile devices.

## Tech Stack 🛠️

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Styling**: Vanilla CSS with modern CSS Variables

## Getting Started 🚀

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Navigate to the project directory:
   ```bash
   cd habitarc
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   *(Note: The `package.json` is configured to run `vite --host` by default, so it will automatically be exposed to your local network).*

4. Open your browser and navigate to the Local or Network IP provided in your terminal.
